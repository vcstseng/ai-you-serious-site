The Screenless Game

The Screenless Game

What would a game become if you explored only through sound?

The idea

Drawn from the screenless voice-controlled game item, this idea considers how sound can convey direction, distance, events and feedback. Removing the screen also calls for rethinking pacing, imagination and accessibility.

The concept is preserved here. The Blindfolded Player and DARK ARCADE are fictional characters; voice recognition, microphone input and game levels have not been implemented.
