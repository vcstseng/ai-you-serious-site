The Neighborhood Tool Library

The Neighborhood Tool Library

What if drills could be borrowed like books?

The idea

Place infrequently used tools in a neighborhood lending model.

Sources and original notes ＋
Source record
100 Niche Markets / Everyday services / 4
Editorial status
Organized for this edition; sources and new extensions distinguished

Original notes

The neighborhood tool-library item imagines how access to objects could circulate locally. Beyond a lending record lie questions of maintenance, waiting, trust and return.

This is a distinct everyday question drawn from Edition 002’s market collection, not an operating lending service. There is no real inventory or borrowing application.
