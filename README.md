# AI You Serious?

[Visit the website](https://vcstseng.github.io/ai-you-serious-site/) · [All editions](https://vcstseng.github.io/ai-you-serious-site/editions/) · [Idea archive](https://vcstseng.github.io/ai-you-serious-site/archive/)

An evolving collection of curious ideas: ten editions, ninety-one canonical ideas, in Chinese and English. Each edition has its own visual world; the homepage opens the latest edition.

- L1: explore an edition. Reading links open canonical L2 pages.
- L2: read an idea through a consistent archive page.
- L3: actual works, linked only when available.

This repository contains the generated public website. Editable content, source code and project documents are maintained separately. Make changes in the source project, then rebuild and publish; do not edit generated pages here.

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` is required. No installation or build step runs in this repository.

Edition 010 is a fictional shopping broadcast: nine ideas return from earlier editions, and one original closing product lets visitors write and download a strange idea. Prices, stock and orders are fictional.
