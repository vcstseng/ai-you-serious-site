街坊工具圖書館

The Neighborhood Tool Library

如果電鑽也像書一樣借閱，社區會少買多少重複的東西？

核心想法 THE IDEA

從「街坊工具圖書館」子題出發，想像物件的使用權如何在鄰里之間流動。一本借閱紀錄之外，還會出現維護、等待、信任與歸還的問題。

它是第二期市場集合的獨立生活題，並非已營運的借用服務。這一輪保留概念，沒有真實庫存或可提交的借閱申請。
